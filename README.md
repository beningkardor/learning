# 个人记账网页 v1.1

这是一个适合初学者练习的简单记账网页，可以添加收入、添加支出、显示消费总记录，并把历史记录保存在浏览器本地。

v1.1 增加了手机可安装的 PWA 支持，以及更细的消费分类。页面可以按月查看消费总记录，并显示每个分类的消费金额。点击快捷消费后，页面会自动选择“支出”并填入消费分类和说明，金额仍然需要自己输入。

## 文件说明

- `index.html`：网页的结构，包含标题、月份选择、消费总记录、分类消费统计、表单和历史记录区域。
- `style.css`：网页的样式，让页面更整洁、易读。
- `script.js`：网页的功能逻辑，负责添加记录、按月查看、分类统计和保存历史记录。
- `manifest.json`：PWA 配置文件，让手机知道这个网页可以安装到主屏幕。
- `service-worker.js`：离线缓存文件，让网页打开过一次后可以继续离线使用。
- `icons/`：手机主屏幕图标。

## 如何运行

直接用浏览器打开 `index.html` 文件即可。

也可以在项目目录运行一个简单本地服务器：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```

## 安装到手机

1. 把项目部署到一个 HTTPS 网站，例如 GitHub Pages。
2. 用手机浏览器打开网站。
3. 在浏览器菜单里选择“添加到主屏幕”或“安装应用”。
