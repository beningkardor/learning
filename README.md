# 个人记账网页 v1.0

这是一个适合初学者练习的简单记账网页，可以添加收入、添加支出、显示当前余额，并把历史记录保存在浏览器本地。

## 文件说明

- `index.html`：网页的结构，包含标题、余额、表单和历史记录区域。
- `style.css`：网页的样式，让页面更整洁、易读。
- `script.js`：网页的功能逻辑，负责添加记录、计算余额和保存历史记录。

## 如何运行

直接用浏览器打开 `index.html` 文件即可。

也可以在项目目录运行一个简单本地服务器：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```
